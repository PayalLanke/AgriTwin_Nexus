# AgriTwin Nexus — Spatial Data Store

This directory serves as the local data cache for spatial files, GeoJSON exports, and satellite band rasters fetched in Module 7+.

---

## 📁 Directory Purpose
- `data/geojson/`: Cached farm boundary polygon GeoJSON files.
- `data/sentinel/`: Downloaded Sentinel-2 multispectral band rasters (Band 2, Band 4, Band 8, Band 5).
- `data/indices/`: Computed index GeoTIFF maps (NDVI, NDRE, SAVI).
